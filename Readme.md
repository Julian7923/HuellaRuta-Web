# 🐾 HuellaRuta — Gestión Inteligente para Paseadores de Perros

Proyecto final para la electiva **Herramientas de IA para la Transformación Digital**.

* **Jose Julian Herrera Pineda**
* **Deglym Sneider Ossa Parra**

## 💡 Descripción del Proyecto
HuellaRuta es una Web App y plataforma digital diseñada para paseadores de perros independientes en Colombia. Permite organizar rutas de recogida, enviar reportes por WhatsApp mediante notas de voz de 4 segundos y automatizar el control de saldos y cobros por Nequi.
